# Design notes

One entry per decision. Interviewers ask "why did you do it that way?", and this file holds your answer.
Write it when you choose between two approaches, while the reasoning is still fresh.

## Template

### <Decision title>
- **Date:**
- **Context:** what problem forced a choice
- **Options:** A, B (and C)
- **Chosen:** which one
- **Why:** the deciding reason (area, speed, simplicity, testability, matching the spec)
- **Revisit when:** what would make you change it (for example, "pipelining in Stage 2")
